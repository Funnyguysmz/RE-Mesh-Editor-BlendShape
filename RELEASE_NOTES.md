# RE4R Face Integration re4r.2 — based on upstream 0.70.6

Merges Dimcirui v0.70.6 (`c030c89f95e6f20c697c402d21b7bae7ec8a52e9`) into our derivative. Includes surface-turn normal mode (new generic default), per-key Static Normals and All/None controls, locked-key base-normal baking, and custom corner-normal protection during quad/n-gon triangulation.

**RE4 semantics are preserved:** both RE4 switches default off. Add RE4 Mouth Receivers still prepends nine specified zero-displacement receiver channels and rejects nonzero same-name conflicts. Keep RE4 Toon Normals still writes packed 11/10/11 delta + int8 normal rows with unknFlag=0 and no normalRecalc section, repeating each vertex's final exported base normal on every key. It does not become per-expression surface-turn export. MODE1, KEEPNORMALS and KEEPNORMALS_SURFACE all enable RE4 keys; the RE4 switch chooses layout. NO ignores both switches. Saved batch flags and older enum values remain compatible.

For RE4, Static on an exported key does not override that final-base payload. When shape-key export is enabled, Static on a locked key suppresses that key's contribution to base-normal turn; other locked keys turn the authored base normals with the surface. Quad/n-gon triangulation now preserves authored corners. No runtime signal, name/hash or model-profile contract changes; System/Studio require no paired code update for this merge.

**Validation:** public synthetic four-switch matrix, default-off bytes identical to upstream 0.70.6, zero receivers, final base-normal payload bytes, packed roundtrip, batch, NO and conflict rejection pass. Additionally 20 upstream Static/locked/surface checks and 24 RE4 normal/selector/quad/pentagon regressions pass. Bundled native libraries are not executed. Package entries match tagged source bytes; GPLv3 license, credits and five original vendor binaries are preserved.

**Prerelease:** prior standalone 85-channel user acceptance is historical. The merged version and integrated 94-channel real-model combination need fresh game feedback. No private models, game resources, recordings or profiles are included. Previous v0.70.6-re4r.1 and its assets remain unchanged.

Install this release's plugin ZIP in Blender 4.3.2 with the older RE Mesh Editor disabled. The addon version tuple remains 0.70.6; derivative revision is exposed as RE4R_INTEGRATION_RELEASE. Keep upstream auto-update disabled and use this fork's releases for derivative updates. A model-specific System profile remains required.
